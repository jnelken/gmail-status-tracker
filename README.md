# gmail-status-tracker

A Google Apps Script project that tracks status events by reading Gmail and syncing them to a Google Calendar and Sheets log. The intention is to automate the capture of status-relevant emails — confirmations, alerts, or updates — into a structured calendar view without manual data entry.

**Current progress:** Google Apps Script project with Gmail integration and a calendar-tracker-sheet subdirectory. Core integration logic exists; polish and reliability improvements are ongoing.

**Final objective:** A fully automated Gmail-to-Calendar status sync pipeline that runs on a schedule and keeps a historical log in Google Sheets.

## Tech Stack

- **Runtime:** Google Apps Script
- **Integrations:** Gmail API, Google Calendar, Google Sheets
